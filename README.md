# アプリ名

(仮)rewatch,映画記録帳

## サービス概要

映画を複数回見る人が、視聴回数ごとの感想の変化を記録・振り返りできるアプリ

私自身、どんでん返し系の映画を見るときに一回目と二回目で振り返りたいと思う場合がありました。
でも、その時の変化を記録できないことが不便に感じていました。
このアプリでは、視聴ごとの感想を時系列で記録し、自分の感じ方の変化を楽しめます。

## 想定ユーザー

- 好きな映画を何度も見返す人
- 初見と2回目以降で感想が変わることを楽しみたい人
- 過去の自分の感想を振り返りたい人
- 映画の感想をXやnoteで発信している人

## ユーザーが抱える課題

- フィルマークスでは、複数回見た時の感想を回数ごとに記録できない
- 初見と2回目以降の感想の違いを振り返る機能がない
- noteやXで感想を書いても、過去の感想を探すのが大変
- 「この映画、また見たい」と思った時に、過去の感想を見返せない

### 実際の声(調査結果より)

- 「複数回見たときの感想の変化を楽しみたいけど、記録する場所がない」
- 「初見と2回目で印象が全然違った。この違いを記録しておきたい」
- 「過去に書いた感想を見返したいけど、Xだと探すのが大変」

## 解決方法

- 視聴回数ごとに感想を記録できる
- 過去の感想を一覧で振り返れる
- 初見と2回目以降の感想を比較表示できる
- 映画ごとに視聴履歴を管理できる

## MVP機能

### ユーザー機能
- ユーザー登録・ログイン

### 映画管理機能
- 映画の検索(TMDb APIを使用)
- 映画の登録

### 感想記録機能
- 視聴回数ごとに感想を記録
- 感想の編集・削除

### 感想振り返り機能
- 過去の感想の一覧表示
- 初見と2回目以降の感想を比較表示
